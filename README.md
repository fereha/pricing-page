# Pricing Page

A simple pricing page built with React, TypeScript, and Vite.

## Features

* Personal pricing plans
* Business & Education plans
* Reusable Card, Button, and Badge components
* Responsive design
* Most Popular plan

## Technologies

* React
* TypeScript
* Vite
* CSS

## Run the Project

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
